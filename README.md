# 1c-task


Машков Данила Вадимович
Алгоритмы 18.10

Сначала мы бесплатно исследуем залы, до которых можно добраться по целым/расчищенным путям, просто запускаем dfsсик для этого. Потом делаем жадник, где на рёбрах пишем 0, если проход свободный, 1, если завален, и 1-p, если у хода вероятность 1-p, что он завален, из Дейкстры мы знаем длину пути до каждого из неоткрытых залов. Потом насчитаем отношения a / b, где a -- ценность залов, через которые мы пройдём, и b -- число денег, которое мы потратим на оплату CLEAR, и мы выбираем путь с наибольшим отношением. Потом повторяем эту процедуру.
